# 全商 情報処理検定 1級 4択クイズ

令和8年度 情報処理検定試験級別出題範囲（全国商業高等学校協会）の第1級に準拠した用語学習サイト。
共通範囲（86語）+ ビジネス情報部門（95語）の全181語を、4択クイズで覚えられる。

## 使い方

`index.html` をブラウザで開くだけ（単一ファイル、外部依存なし）。
GitHub Pages ではリポジトリルートに置いてそのまま公開できる。

## 機能

- 用語→意味 / 意味→用語 の両方向をランダム出題
- 出題範囲の絞り込み（すべて / 共通 / ビジネス情報 / 分野別）
- 同じ分野の用語を優先した紛らわしい選択肢
- 正答率・連続正解数の表示
- 学習記録を localStorage に保存（苦手優先モード・間違えた語だけモード）
- キーボード操作（1〜4 で回答、Enter で次へ）

## ファイル

- `index.html` — クイズサイト本体（用語データ埋め込み済み）
- `terms.json` — 用語データ（出題範囲準拠）
